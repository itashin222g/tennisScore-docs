加点はタップ、操作は上下スワイプ

Wear OSの左右スワイプ操作と干渉しないように、加点は画面の左側・右側をタップ。上下スワイプでメニューと取り消しを行います。

→
You +1 point

画面の左側をタップして、自分のポイントを追加します。

←
Opponent +1 point

画面の右側をタップして、相手のポイントを追加します。

↑
Menu

上方向のスワイプで設定、履歴、サマリーなどを開きます。

↓
Undo

下方向のスワイプで直前の操作を取り消します。

記録も振り返りも腕元で

現在のスコアだけでなく、ポイント理由、試合サマリー、過去の履歴まで残せます。

01 自動スコア進行

0、15、30、40、Ad、ゲーム、セットをルールに合わせて進めます。

02 タイブレーク対応

タイブレークの有無、到達点、2点差ルールを設定できます。

03 ポイント理由

Ace、Unforced Error、Volleyなど、得点理由をあとから集計できます。

04 履歴保存

終了した試合の勝者とログを保存し、あとで見返せます。

小さな画面に必要な情報だけ

スコア画面では、中央にポイント、下部にセットとゲーム、サーバー表示を配置。試合中に一瞬で状態を確認できます。

Score

You / Opponent のポイントを大きく表示。サーバー側にはテニスボールのアイコンを表示します。

Summary

ポイント理由ごとのカウントと割合を確認できます。

Presets

よく使う試合ルールを保存して、次回すばやく呼び出せます。

試合ルールを柔軟に設定

練習、短いゲーム、正式ルール寄りの試合など、場面に合わせて設定できます。

Sets to Win 勝利に必要なセット数を設定
Games / Set 1セットを取るためのゲーム数を設定
First Serve 最初のサーバーをYou / Opponentから選択
Start 15-all 15-15から始める練習形式にも対応
Deuce デュースあり / なしを切り替え
TieBreak タイブレークの有無とポイント数を設定

腕元で、試合の流れを逃さない。

TennisScoreは、試合中の操作をできるだけ少なくしながら、あとで振り返れる情報を残すWear OS向けスコアトラッカーです。
